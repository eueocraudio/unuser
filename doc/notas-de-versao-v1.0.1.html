unuser — Notas de Versão

Cliente v1.0.1

04/06/2026 · sincronização manual com cofre cifrado (zero-knowledge)

Primeira versão marcada do cliente (unuser): um corte de bug crítico de integridade e a repaginação completa da interface gráfica. Guia de instalação e uso no Manual do Usuário (doc/manual-usuario-unuser.html / PDF).

Correção crítica

block_id por arquivo — corrupção de dedup entre arquivos. Blocos de conteúdo idêntico em arquivos diferentes geravam o mesmo block_id (chave global) e colapsavam num único blob no servidor (endereçado por conteúdo), cifrado com a FK de só um deles — deixando o(s) outro(s) irrecuperável(is) ao decifrar. Agora a chave do block_id é derivada por arquivo da FK (HKDF). A dedup dentro do mesmo arquivo é preservada e não há migração. Cofres já corrompidos: reenviar os arquivos afetados regrava blobs corretos.

Novidades da interface gráfica

  • Layout Explorer de duas áreas, tema escuro: árvore de pastas à esquerda; lista dos arquivos diretamente na pasta selecionada à direita (não recursivo), com as 6 cores de status.
  • Ícones de pasta e arquivo (padrão do Qt, sem assets proprietários).
  • Adicionar arquivo: envia um arquivo escolhido; se estiver fora das pastas sincronizadas mas dentro de ~/, registra a pasta automaticamente (ou o arquivo como item avulso, se estiver direto em ~/).
  • Tela "Pastas…": listar/adicionar/remover pastas sincronizadas e itens avulsos.
  • Estado lembrado entre sessões: expansão da árvore e pasta selecionada (em ~/.local/data/unuser/).
  • As operações de rede não travam a janela (rodam fora da thread da interface).

Outras melhorias

  • Scripts de execução: src/server/run.sh, src/client/run.sh e src/client/run-gui.sh (instala PySide6 e resolve libxcb-cursor0 sem root).
  • Configuração mutável do dirs.json e mapeamento caminho local → vault path (resolve_or_register).
  • Documentação: manual do usuário em HTML + PDF (com instalação).

Instalação rápida

sh packaging/build-deb-client.sh
sudo apt install ./dist/unuser_1.0.1_amd64.deb
sudo apt install python3-pyside6.qtwidgets libxcb-cursor0   # para a GUI
unuser gui
Requer Debian 13 (trixie) / Python 3.13. O blake3 vai embarcado no pacote; o CLI funciona sem o PySide6.

Compatibilidade e segurança

  • Sem mudança no protocolo nem no formato do manifesto (sem migração).
  • Cofre zero-knowledge: o servidor nunca vê conteúdo, nomes ou chaves. Confidencialidade depende de passphrase + keyfile — faça backup do keyfile; sem ele (ou a passphrase) o cofre é irrecuperável.
  • Acesso remoto por Tor + mTLS.
